# Qaydasız feillər (Irregular Verbs)

Uşaqlar üçün sadə, rəngli dərslik: **66 qaydasız feil**, asan əzbərləmək üçün 5 qrupa bölünüb.

- **Fayl:** [qaydasiz-feiller.pdf](qaydasiz-feiller.pdf) (A4, 11 səhifə)
- **İçində:** feilin 3 forması nədir, qaydalı/qaydasız feil fərqi, 7 əzbərləmə fəndi,
  5 qrup üzrə cədvəllər (3 forma + tələffüz + tərcümə), əlifba sırası ilə ümumi cədvəl,
  lüğət (20 söz), 5 çalışma və cavablar.
- **Qruplar:** üçü də eyni (cut) · 1-ci = 3-cü (come) · 2-ci = 3-cü (buy) · i–a–u (sing) · hamısı fərqli (go).
